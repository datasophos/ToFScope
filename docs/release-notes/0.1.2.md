# ToFScope 0.1.2

## Highlights

- Explore the new [ToFScope documentation](https://datasophos.github.io/ToFScope/), including installation, analysis, visualization, configuration, and technical guides.
- When opening an analysis, ToFScope now selects the strongest stored spectral peak at or above m/z 20 by default, falling back to another stored peak when none meets that threshold.
- Signal, identification, and 3D controls use clearer m/z labels. Isotope measurements now display their pre-alpha status.
- Service restarts can rebind the existing port more promptly on non-Windows systems.

## Command-line change

`tofscope doctor` now prints a concise human-readable status by default. Use `tofscope doctor --json` for the structured report previously printed by default; scripts that parse its output should add `--json`.
