## Highlights

- Explore now initially selects the strongest stored spectral peak at or above m/z 20, falling back to the available peaks when none meet that threshold.
- Scientific labels now use m/z consistently; peak identification and 3D intensity controls have clearer names. Isotope measurements are marked pre-alpha.
- A reorganized documentation site provides illustrated guides for analysis, calibration, identification, 3D views, saving, and raw preparation, along with deployment and developer guidance.
- The service can rebind its port promptly after closed connections on non-Windows systems.

## Command-line change

`tofscope doctor` now prints a short human-readable status by default. Use `tofscope doctor --json` to obtain the detailed JSON report previously printed by default; update scripts that parse the output.
