## Windows secondary-electron previews

Fixed an error that could prevent 3D views from opening on Windows when an acquisition contains secondary-electron (SE) images. Parallel SE processing now produces a valid worker response; the same fix applies to averaged SE images in Explore.

## Saving and version information

- Saving a copy now waits for pending analysis edits to finish, preventing a save from failing when a signal rename completes at the same time.
- The application footer shows the running ToFScope version and links to its release notes.
