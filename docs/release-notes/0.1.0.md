# ToFScope 0.1.0

First ToFScope release for exploring TOFexplorer acquisitions locally.

- Explore ion images, mass spectra, depth profiles, and 3D views.
- Define and compare signals, calibrate depth, and identify isotope candidates.
- Save analyses as new HDF5 copies without changing the original acquisition.

ToFScope is in alpha. Self-hosted multi-user and container deployment remain under development. See the installation and user guides for setup and current limitations.
