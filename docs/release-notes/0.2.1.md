## Windows support

ToFScope now runs on Windows as well as macOS and Linux. Windows users can install and launch the application, explore acquisitions, save analysis copies, and download saved files. The [installation guide](https://datasophos.github.io/ToFScope/docs/getting-started/installation.html) includes a PowerShell example and Windows runtime-directory guidance.

## Compatibility and reliability

- Python 3.11 through 3.14 are supported. Python 3.15 and newer are excluded until compatible dependencies are available.
- Unreadable acquisitions now report a clearer error with suggestions for checking the file and drive.
- Packaged frontend asset checks and saved-file operations are more portable across operating systems.
