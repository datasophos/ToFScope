**Goal:** Give the first macOS user a guided uv installation from a Git clone.

**Architecture:** Keep the existing bundled Python application and document a separate user walkthrough and release preparation checklist. Verify the distribution using existing checks where the environment permits.

**Tech Stack:** macOS, uv, Python 3.11+, Git.

**Spec:** Approved conversation design: guided installation from a clone, launch, update, removal, and ToFScope limitations.
